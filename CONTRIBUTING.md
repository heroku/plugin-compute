# Contributing

Thanks for your interest in `@salesforce/plugin-compute`!

## Bug Reports & Feature Requests

Please file an issue at https://github.com/forcedotcom/cli/issues.

## Pull Requests

1. Fork and clone the repo, then run `yarn install`.
2. Make your change on a branch off `main`.
3. Run `yarn build` and `yarn test` and make sure both pass.
4. Commit messages must follow [Conventional Commits](https://www.conventionalcommits.org/) — this is enforced by commitlint via a pre-commit hook.
5. Open a PR against `main`.

## Code of Conduct

This project follows the [Salesforce Open Source Community Code of Conduct](CODE_OF_CONDUCT.md).
